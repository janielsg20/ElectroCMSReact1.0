## Decisión de alcance

No se utilizará ninguna aplicación existente como referencia. El usuario indicó expresamente que ElectroCMS debe construirse desde cero siguiendo únicamente los archivos Markdown canónicos de este repositorio.

La sección 2 de `PROMPT_MAESTRO_ELECTROCMS.md` se conserva íntegra, pero no existe un artefacto React adjunto autorizado que pueda inventariarse. Ningún proyecto, repositorio o carpeta externa se considera sustituto implícito.
