# Accesibilidad

Objetivo: WCAG 2.2 AA en editor y proyectos generados.

- Semántica HTML, nombres accesibles, jerarquía de headings y landmarks.
- Operación completa con teclado y foco visible/no oculto.
- Reflow a 320 CSS px; zoom 200/400 %; texto escalable.
- Contraste 4.5:1 para texto normal y 3:1 para UI/no-texto cuando corresponda.
- Targets internos de 44 × 44 CSS px para controles críticos.
- Alternativa de una sola activación y teclado a toda acción de drag.
- Errores claros, asociados y anunciados; color nunca como único indicador.
- Reduced motion, orientación y screen readers incluidos en pruebas.

Consulta `UI_UX_LAYOUT_SYSTEM.md` para el patrón responsive.
